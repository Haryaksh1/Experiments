# Experiments

A collection of small, self-contained experiments. Each one lives in its own folder with its own README.

| Folder | What it is |
|---|---|
| [simple-rag](simple-rag/) | Five RAG architectures (vector, keyword, hybrid, tree, graph) compared side by side on Indian legal statutes |
| [kamikaze-skill](kamikaze-skill/) | A Claude skill that drops every other skill active in a chat, then retires itself |
