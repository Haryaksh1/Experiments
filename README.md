# Experiments

A collection of small, self-contained experiments. Each one lives in its own folder with its own README.

| Folder | What it is |
|---|---|
| [simple-rag](simple-rag/) | Five RAG architectures (vector, keyword, hybrid, tree, graph) compared side by side on Indian legal statutes |
| [kamikaze-skill](kamikaze-skill/) | A Claude skill that drops every other skill active in a chat, then retires itself |
| [voice-browser](voice-browser/) | Control Chromium with your voice using local Whisper speech to text and Playwright. [Read the Medium post](https://medium.com/@haryakshbhardwaj/is-speech-recognition-still-the-hard-part-of-a-voice-controlled-browser-82067c75daad) |
| [agents-lab](agents-lab/) | Four AI agent systems for decision making and simulation (a single agent and a three agent debate, generative agents, silicon survey samples with PPI++, a public goods game), running fully offline on phi3:mini |
